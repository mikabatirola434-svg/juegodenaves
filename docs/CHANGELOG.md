# CHANGELOG

Todos los cambios importantes del proyecto se documentan en este archivo.

## [v1.0.0] - 2026-10-21

### Agregado
- Código base del juego de naves en consola desarrollado en C++.
- Clases `Nave`, `Asteroide` y `Bala` para organizar los elementos del juego.
- Constructor para inicializar los objetos y métodos públicos para controlar sus acciones.
- Movimiento de la nave mediante las teclas W, A, S y D.
- Sistema de disparos utilizando la barra espaciadora.
- Generación y movimiento de asteroides con posiciones aleatorias.
- Detección de colisiones entre la nave, las balas y los asteroides.
- Sistema de tres vidas y finalización de la partida.
- Solicitud del nombre y apellido del piloto al iniciar el programa.
- Documentación inicial del proyecto: README, manual técnico del programador y manual técnico del usuario.

### Documentación
- Creación de la estructura de carpetas del repositorio.
- Incorporación de las referencias técnicas de C++, constructores, modificadores de acceso y Git.
